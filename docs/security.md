## 应用侧边界

- 记录以文本显示，不使用 HTML 注入。
- JSON 严格验证已知字段、编号、情绪、日期、活动、条数与 UTF-8 大小；非法导入不修改现有数据。
- CSV 对公式样式开头加前导单引号，并正确转义逗号、引号与换行。
- 写入失败不伪报成功；损坏数据保留原始内容。
- Service Worker 只缓存同站点的应用资源；不把日记放入静态缓存或上传。
- 本地数据和备份没有单独加密。设备保护、浏览器站点隔离和文件保管仍由用户掌握。
